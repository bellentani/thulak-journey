# A Descoberta de Thulak

Jogo de suspense em alta fantasia, inspirado nos RPGs e livros-aventura que rodavam em terminais e nos tempos de DOS.

## Rodar

```bash
npm start
```

## Verificar

```bash
npm run check
```

## Resumo da historia

```bash
npm run story:summary
```
